Theory & Models

Short Transmission Line

For a short transmission line, shunt capacitance is neglected.

A = D = 1,   B = Z,   C = 0

Medium Transmission Line

The nominal-π model is used for medium transmission lines.

A = D = 1 + YZ/2

B = Z(1 + YZ/4)

C = Y(1 + YZ/4)

Long Transmission Line

The exact distributed parameter model is used for long transmission lines.
